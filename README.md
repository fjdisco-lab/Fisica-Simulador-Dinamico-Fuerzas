# Estudio Joaco | Laboratorio de Dinámica

Un simulador interactivo de física clásica diseñado para estudiantes de colegios técnicos y especializaciones aeronáuticas. Esta herramienta permite visualizar y calcular en tiempo real el comportamiento de las fuerzas en un plano inclinado, fomentando el pensamiento crítico y la precisión técnica.

## Propósito Académico

El objetivo de este laboratorio virtual es actuar como un recurso de apoyo técnico, desglosando conceptos complejos de la mecánica clásica (base de la aerodinámica y estructuras aeronáuticas) en variables manipulables. 

Los estudiantes pueden experimentar de forma segura cómo interactúan:
* La descomposición trigonométrica del peso (Vectores Px y Py).
* La fricción estática y cinética frente a variaciones de carga.
* El impacto de fuerzas externas aplicadas en diferentes ángulos.
* Las condiciones para mantener el equilibrio o generar aceleración.

## Características Técnicas

* **Cálculo en Tiempo Real:** Las fórmulas trigonométricas de la Segunda Ley de Newton operan instantáneamente al modificar cualquier parámetro.
* **Renderizado Vectorial:** Representación visual de los vectores de fuerza (Normal, Peso, Empuje, Fricción) en un lienzo dinámico.
* **Telemetría Integrada:** Panel de resultados pedagógicos que no solo muestra los valores, sino que expone las fórmulas utilizadas para llegar a ellos.
* **Diseño Adaptativo (Mobile-First):** Interfaz optimizada para ser utilizada como herramienta de campo en dispositivos móviles o calculadoras de bolsillo.

## Instrucciones de Despliegue y Uso

El simulador está construido en un único archivo de arquitectura limpia (HTML5 + Vanilla JavaScript) sin dependencias externas, garantizando su funcionamiento offline o en servidores estáticos.

1. Navegar a la página alojada a través de GitHub Pages.
2. Utilizar el panel superior para ajustar las variables de entorno (ángulo de rampa, fricción) y del objeto (masa, fuerzas aplicadas).
3. Analizar la telemetría para comprender la distribución de las fuerzas.
4. Ejecutar la simulación para comprobar el resultado cinemático.

## Estándar de Instrucción

Este proyecto se rige por los principios de instrucción técnica aeronáutica:
* **Rigor Analítico:** Los cálculos priorizan la exactitud física por encima de las simplificaciones.
* **Pensamiento Crítico:** La herramienta no da respuestas de exámenes; proporciona el entorno para deducirlas.
